### 🧠 Sobre Mim

Sou o Vitor, iniciei meus estudos em ADS no ano de 2026 e há 3 anos busco aprimorar minhas habilidades e conhecimentos com código. Minha área principal é o JavaScript, mas atualmente estou explorando outras linguagens como Rust, Clojure e Python, além de aprimorar meus conhecimentos em HTML e CSS. Neste perfil, serão exibidos tanto projetos independentes quanto projetos acadêmicos.

- 🚀 Atualmente desenvolvendo um **Bot para WhatsApp** focado em automação e interações inteligentes.
- 📝 Concluindo a **Documentação de Software** e modelagem estrutural para fins acadêmicos.
- 👥 Desenvolvendo em equipe o sistema de banco de dados em **MySQL** e o site para o projeto [doces_sobre_rodas](https://github.com/SyntaxKills/doces_sobre_rodas) (créditos e contribuições de toda a equipe especificados no repositório!).
